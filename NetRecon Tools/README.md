netrecon.sh
The purpose of this script is to identify active devices on a network and check which services are accessible on those devices.

sshguard.sh
SSH Login Analyzer is a Bash-based security tool that analyzes SSH authentication logs and detects failed login attempts. It identifies IP addresses with multiple failed attempts and marks them as suspicious based on a configurable threshold. The tool also generates a CSV report containing the detected IPs, failed attempt counts, and their status.
